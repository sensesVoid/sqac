# SQAC 0.2.0 — Bundled SIMD + CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `sqac` 0.2.0 so `pip install sqac` includes the Rust SIMD extension on every supported platform, with a NumPy fallback, a green Python/Rust test matrix, cibuildwheel artifacts, and OIDC-based PyPI releases.

**Architecture:** Move the existing `sqac-simd` crate inside the `sqac` wheel as `sqac._simd` using `setuptools-rust` with `optional=True` and abi3. Keep a thin `sqac.simd` shim so imports work with or without the extension. CI builds and tests the extension on Linux/macOS/Windows; a separate job proves the fallback. Wheel and sdist artifacts feed a Trusted Publishing release workflow.

**Tech Stack:** Python 3.10–3.13, setuptools ≥77, setuptools-rust ≥1.13, pyo3 0.30, Rust stable, pytest, ruff, cibuildwheel 4.3.5, GitHub Actions, PyPI Trusted Publishing.

**Spec:** `docs/superpowers/specs/2026-11-15-sqac-v1-design.md` (Workstream 1, §8; hardening items in §12.1 apply where this plan touches them).

## Global Constraints

- Supported Python: `>=3.10`; CI matrix is 3.10, 3.11, 3.12, 3.13. Python 3.14 is best-effort, not a release gate.
- Supported wheel platforms: Linux x86_64 + aarch64, macOS x86_64 + arm64, Windows AMD64. Windows ARM64 is best-effort.
- Rust extension module name is exactly `sqac._simd`; Python wrapper is `sqac.simd`.
- `pyo3 = "0.30"` with `abi3-py310`; wheels are `cp310-abi3`.
- `target-cpu = "native"` must not appear anywhere in `sqac-simd/Cargo.toml`.
- `setuptools>=77`, `wheel`, `setuptools-rust>=1.13` in `build-system.requires`.
- Runtime dependency is `numpy>=1.24` with no upper pin. `sentence-transformers` is removed from all extras.
- MCP extra is `mcp>=2.0,<3`; `sqac_mcp.py` uses `mcp.server.mcpserver.MCPServer`, absent in 1.x.
- `SQAC_SKIP_RUST=1` must produce a working pure-Python install with `sqac.simd.HAS_SIMD is False`.
- No PyPI API token or password is stored in GitHub. Publishing uses OIDC, environment `pypi`, workflow `release.yml`.
- Release version is `0.2.0`, tag `v0.2.0`. Do not change the `.sqac` binary format in this plan (header version stays 4).
- Existing `.sqac` files must remain readable; run the full suite after every task.

## Review Focus

These are the failure modes most likely to reach a user despite green unit tests. Each one has a test in the owning task.

1. **A wheel built with host-specific CPU flags crashes on another machine.** Expected: imports and runs on a baseline runner. Pinned by Task 3's no-`target-cpu` check and Task 7's wheel test.
2. **The extension is silently absent but the code claims SIMD is on.** Expected: `HAS_SIMD` reflects reality and the store falls back cleanly. Pinned by Task 4's shim tests and Task 6's fallback job.
3. **A module still fails to parse on 3.10/3.11.** Expected: every matrix job imports the package. Pinned by Task 1's compile check and the CI matrix.
4. **The sdist omits Rust sources, so `pip install --no-binary sqac` fails.** Expected: the sdist can rebuild the extension. Pinned by Task 7's tarball assertion.
5. **Release authentication is misconfigured.** Expected: a TestPyPI dry run succeeds before the first real tag. Pinned by Task 8's dry-run step and Task 10's tag checklist.

```python
"""Parity tests for the bundled Rust SIMD backend."""

import random
import unittest

import numpy as np

from sqac.simd import HAS_SIMD, backend


def _vectors(n=32, key_len=128):
    rng = random.Random(1234)
    query = bytes(rng.randrange(256) for _ in range(key_len))
    keys = [bytes(rng.randrange(256) for _ in range(key_len)) for _ in range(n)]
    ckeys = [bytes(rng.randrange(256) for _ in range(key_len)) for _ in range(n)]
    return query, keys, ckeys


class TestSimdFlag(unittest.TestCase):
    def test_flag_matches_store_stats(self):
        from sqac.store import SqacStore

        self.assertEqual(SqacStore().stats()["simd"], HAS_SIMD)


@unittest.skipUnless(HAS_SIMD, "Rust extension not built")
class TestSimdParity(unittest.TestCase):
    def test_bulk_similarity_matches_numpy(self):
        query, keys, _ = _vectors()
        dims = len(query) * 8
        got = backend.bulk_similarity(query, b"".join(keys), len(keys), dims)
        q = np.unpackbits(np.frombuffer(query, dtype=np.uint8))
        for i, key in enumerate(keys):
            v = np.unpackbits(np.frombuffer(key, dtype=np.uint8))
            expected = 1.0 - float(np.count_nonzero(q != v)) / dims
            self.assertAlmostEqual(got[i], expected, places=12)

    def test_pack_and_similarity_matches_numpy(self):
        query, keys, ckeys = _vectors()
        dims = len(query) * 8
        live = list(range(len(keys)))
        sims_k, sims_c = backend.pack_and_similarity(
            query, keys, ckeys, live, len(query), dims
        )
        q = np.unpackbits(np.frombuffer(query, dtype=np.uint8))
        for i, (key, ckey) in enumerate(zip(keys, ckeys)):
            for src, got in ((key, sims_k[i]), (ckey, sims_c[i])):
                v = np.unpackbits(np.frombuffer(src, dtype=np.uint8))
                expected = 1.0 - float(np.count_nonzero(q != v)) / dims
                self.assertAlmostEqual(got, expected, places=12)

    def test_identical_and_opposite(self):
        dims = 1024
        zero = bytes(dims // 8)
        ones = b"\xff" * (dims // 8)
        sims = backend.bulk_similarity(zero, zero + ones, 2, dims)
        self.assertAlmostEqual(sims[0], 1.0, places=12)
        self.assertAlmostEqual(sims[1], 0.0, places=12)
```

**Files:**

- Consumes: `wheels.yml` via `workflow_call`.

- [ ] **Step 1: Create `.github/workflows/release.yml`**

```yaml
name: Release

on:
  push:
    tags: ["v*"]
  workflow_dispatch:
    inputs:
      testpypi:
        description: Publish to TestPyPI instead of PyPI
        type: boolean
        default: true

permissions:
  contents: read

jobs:
  wheels:
    uses: ./.github/workflows/wheels.yml

  publish:
    needs: wheels
    runs-on: ubuntu-latest
    environment: ${{ inputs.testpypi && 'testpypi' || 'pypi' }}
    permissions:
      id-token: write
    steps:
      - uses: actions/download-artifact@v4
        with:
          path: dist
          pattern: "*"
          merge-multiple: true
      - name: Publish to TestPyPI
        if: ${{ inputs.testpypi }}
        uses: pypa/gh-action-pypi-publish@release/v1
        with:
          packages-dir: dist
          repository-url: https://test.pypi.org/legacy/
      - name: Publish to PyPI
        if: ${{ !inputs.testpypi }}
        uses: pypa/gh-action-pypi-publish@release/v1
        with:
          packages-dir: dist

  github-release:
    if: startsWith(github.ref, 'refs/tags/v')
    needs: publish
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/download-artifact@v4
        with:
          path: dist
          pattern: "*"
          merge-multiple: true
      - uses: softprops/action-gh-release@v2
        with:
          generate_release_notes: true
          files: dist/*
```
