# SQAC 0.3.0 Vault Cartridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reference-only encrypted `vault` cartridge (v0.3.0) that stores secrets/PII as AES-256-GCM ciphertext, exposes values only via `vault exec` env injection and a host-allowlisted HTTP proxy, and is never readable through normal search/rack/MCP getter paths.

**Architecture:** Introduce header version 5 for vault cartridges (memory/agent remain v4) with `FLAG_ENCRYPTED` entries and plaintext metadata. Implement `sqac/vault.py` (API + CLI-facing ops), `sqac/vault_crypto.py` (DEK/KEK, AES-GCM, keychain/Argon2id, unlock cache), `sqac/pii.py` (pattern detection), and `sqac/vault_audit.py` (hash-chained JSONL). Wire CLI subcommands, MCP metadata/proxy tools, and rack/search isolation by `cartridge_type`. No MCP tool returns or accepts plaintext secret values.

**Tech Stack:** Python 3.10+, stdlib (`json`, `base64`, `os`, `hmac`, `hashlib`, `subprocess`, `urllib`, `getpass`, `secrets`, `re`, `dataclasses`), `numpy` (existing), `cryptography` (AESGCM/PBKDF primitives already common; if unavailable add minimal optional dep or use `hazmat`), `keyring` (OS keychain), `argon2-cffi` (Argon2id). Prefer `cryptography` for AEAD/KDF; add `vault = ["cryptography>=42", "keyring>=25", "argon2-cffi>=23"]` and include in dev/test where needed.

**Spec:** `docs/superpowers/specs/2026-11-15-sqac-v1-design.md` (§9 Workstream 2 — Vault cartridge, plus G2/non-goals/anti-goals/constraints/risks).

## Global Constraints

- Python `>=3.10`; keep CI matrix green (Linux/macOS/Windows, 3.10–3.13).
- v1 has exactly one vault: `~/.sqacm/vaults/default.sqac`, internal name `default`; no `--vault` selector and no multi-vault refs in v1.
- Header `extra["cartridge_type"]="vault"`; vault files write header **version 5** (`FLAG_ENCRYPTED=0x0008` on every vault entry). Memory/agent continue to write v4. Readers accept `version <= 5`; pre-v5 readers must fail closed on vault files.
- Plaintext secret/PII values are **never** returned by MCP tools, never embedded in search results/rack, never written to audit/session logs, never uploaded as key material. MCP exposes only `vault_list`, `vault_meta`, `vault_http`, `vault_audit`; **no** `vault_get/resolve/put/exec`.
- Crypto: AES-256-GCM, random 96-bit nonce per entry, 32-byte DEK per vault, AAD `sqac-vault-v1|default|<name>|<entry_type>`. KEK via OS keychain (default, `sqac-vault`/`default`) or Argon2id (`time_cost=3,memory_cost=65536,parallelism=4`, 16-byte salt). Keychain-missing → passphrase prompt/env; never persist raw keys to disk.
- Values: 64 KB cap per entry; names opaque (warn if name looks like email/phone). `put` reads value from stdin/TTY or `--from-env`/`--from-file`, never argv.
- `vault exec`: resolve only explicitly mapped vars, strip `SQAC_VAULT_*` from child env, default redaction of resolved values in stdout/stderr as `[REDACTED:vault:NAME]`.
- `vault_http`: stdlib `urllib.request`, HTTPS only, exact `allowed_hosts` required (no wildcards by default), redirects only to allowlisted hosts (max 5), auth `bearer|header:<name>|query:<param>`, response capped 1 MB, timeout 30s, request headers not returned.
- Audit `~/.sqacm/vault-audit.jsonl`: hash-chained records (`prev` SHA-256), fields `ts,vault,name,op,host,session,pid,success,bytes,error?`, **no values**.
- Isolation: rack auto-load/register/search-target collection skips `vault` and `agent` by header `cartridge_type` (not by name). `mem_search` never returns vault entries. `mem_write` warns on PII-like content but stores it (memory is plaintext).
- Sync contract (for later 0.5.0, enforced now in API/metadata): keychain-mode vaults local-only; portable/passphrase vaults are ciphertext-only bytes; never sync `vault-audit.jsonl`.

## Review Focus

- **Plaintext leak paths:** grep tests + MCP/tool behavior prove no tool, search result, audit record, exception message, or log contains a stored secret value (including partials) under normal and error paths.
- **Tamper/wrong-key fail-closed:** modified ciphertext, nonce, tag, AAD components, or wrong passphrase/key raises a clear auth/decrypt error and never returns partial plaintext.
- **Isolation by type, not name:** a normal memory cartridge named `vault`/`agent` remains searchable; an actual `vault` cartridge (type) is excluded from rack/search/auto-load even if explicitly present in memory dirs.
- **HTTP policy enforcement:** non-HTTPS, non-allowlisted host, redirect to non-allowlisted host, wildcard host, oversized response, and timeout are rejected/capped without leaking the secret into the error body.
- **Locked/non-interactive MCP:** with no keychain key and no `SQAC_VAULT_PASSPHRASE`, metadata ops succeed and value ops/proxy return structured `vault_locked` (no prompt/hang) in stdio server context.

**Interfaces:**

  - `derive_kek_argon2id(passphrase: str, salt: bytes, time_cost=3, memory_cost=65536, parallelism=4) -> bytes`.
  - `wrap_dek(dek: bytes, kek: bytes) -> tuple[str, str]` / `unwrap_dek(wrap_nonce_b64: str, wrapped_b64: str, kek: bytes) -> bytes` (AES-256-GCM).
  - `keychain_get/set/delete(service="sqac-vault", username="default")` wrappers over `keyring` with `KeychainUnavailable` fallback signaling.
  - `VaultUnlockCache` (or module-level cache) keyed by `(path, mtime)` storing unwrapped DEK in memory; `clear(path=None)`.

import base64
import unittest

class TestVaultCrypto(unittest.TestCase):
    def test_roundtrip_and_aad_binding(self):
        from sqac.vault_crypto import generate_dek, encrypt_value, decrypt_value, VaultCryptoError
        dek = generate_dek()
        n, ct = encrypt_value(dek, b"secret", vault="default", name="openai", entry_type="secret")
        self.assertEqual(decrypt_value(dek, n, ct, vault="default", name="openai", entry_type="secret"), b"secret")
        with self.assertRaises(VaultCryptoError):
            decrypt_value(dek, n, ct, vault="default", name="other", entry_type="secret")

    def test_wrap_unwrap_and_argon2id(self):
        from sqac.vault_crypto import generate_dek, wrap_dek, unwrap_dek, derive_kek_argon2id
        import os
        dek = generate_dek(); salt = os.urandom(16)
        kek = derive_kek_argon2id("pass", salt)
        wn, wct = wrap_dek(dek, kek)
        self.assertEqual(unwrap_dek(wn, wct, kek), dek)

    def test_wrong_passphrase_fails(self):
        from sqac.vault_crypto import generate_dek, wrap_dek, unwrap_dek, derive_kek_argon2id, VaultCryptoError
        import os
        dek = generate_dek(); salt = os.urandom(16)
        wn, wct = wrap_dek(dek, derive_kek_argon2id("a", salt))
        with self.assertRaises(VaultCryptoError):
            unwrap_dek(wn, wct, derive_kek_argon2id("b", salt))
